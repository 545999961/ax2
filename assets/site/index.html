01 / Research question

Self-improvement is a test-time skill.

We define self-improvement as the ability to iteratively refine a solution during one task. It is a form of test-time scaling: giving the agent more useful rounds should, in expectation, lead to a better result.

Two abilities make that possible. Reflection makes the next proposal better than the current one. Long-horizon execution keeps enough rounds useful to carry the improvement through.

initial solution×(1 + r)T

r is the expected gain from one revision; T is the number of effective rounds. The expression is a model of the mechanism, not a claim of monotonic scores.

02 / Training data

Teach improvement where progress is measurable.

Long-horizon reflective traces are rare in ordinary training data. We build them in environments with clean feedback, room to improve, and enough material for many attempts.

A

Data self-evolution

Start from GitHub repositories and online-judge problems. A teacher model turns them into executable tasks, sandboxes, and scoring functions, then samples complete improvement trajectories.

Keep the whole run: successes, regressions, reversions, and changes of strategy.

B

Machine learning

Validation scores make each experiment legible. Rich repositories and optimization headroom let an agent move from a baseline to a stronger pipeline.

Clean, continuous feedback
C

Algorithmic programming

Tests and judge scores expose correctness and efficiency. Problems, reference solutions, and scoring functions support sustained iteration.

Verifiable feedback
